# HyperOS 4 — Mi Dialer & Mi Messages Suite (Android APK Ready)

## Included Features
- **Authentic HyperOS 4 Squircles & Soft Light Glass UI** (Light Mode & OLED Dark Mode)
- **Mi Dialer (Phone)**: T9 predictive search, Dual SIM 1 / SIM 2 HD VoLTE calling, Live In-Call screen with Auto & Manual Call Recording, HyperIsland minimized call pill, DTMF keypad, Hold, Add Call, Speaker/Bluetooth, Call History with recording playback, Contacts with A–Z scrubber, and Xiaomi Yellow Pages.
- **Mi Messages**: Smart OTP Verification Cards with 1-tap Copy, categorized inbox (`All`, `Unread`, `Verification`, `Transactions`, `Promotions`), Dual SIM SMS composer, Scheduled SMS sending, Smart Quick Replies, and Spam Shield.

## Build the `.apk` on GitHub
1. Upload all files from this folder to a GitHub repository.
2. Open the **Actions** tab and wait ~2 minutes for **Build Android APK** to turn green.
3. Download **HyperOS4-Dialer-Messages-APK** under **Artifacts** and install `app-debug.apk` on your Android phone.
